RUNNERIMAGES

Deterministic Docker images for CI runners. Pinned digests, locked versions, reproducible builds. No surprises.

forgejo-actions workflow 
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    container:
      image: ghcr.io/wyattau/runner-images/ubuntu:1
    steps:
      - uses: actions/checkout@v4
      - run: docker build -t app .
      - run: make test

Architecture

Three layers. Zero waste.

Layer 0

Base

ubuntu:24.04@sha256:<digest> -- pinned by SHA256 digest. Prevents supply-chain drift. ~78 MB uncompressed.

Layer 1

BU Base

Shared build utilities: git, curl, jq, make, gcc, wget, zip, openssl, and more. Shared across all flavours. ~250 MB uncompressed.

Layer 2

Flavour

Flavour-specific packages and user setup. Docker deduplicates Layers 0 and 1 across images. Max 4 layers enforced at build time.

Pillars

Six principles. Zero compromises.

P1

Deterministic

Pinned base digests, pinned package versions, SHA256-verified tarballs. A build is the same bitstring every time. No "works on my machine."

P2

Thin

Compressed budget enforced at build time. No man pages, no docs, no static libs, no caches. Every byte earns its place.

P3

Secure

No SUID except sudo, no world-writable files, no secrets in image. Trivy scans in CI. Minimal attack surface.

P4

Compatible

amd64 architecture, standard UID/GID 1000, Docker CLI for sibling containers. Works with any standard Forgejo or GitHub Actions workflow.

P5

Auditable

OCI labels, versions.lock per build, SBOM generation with syft, cosign signing. Every component traceable.

P6

Maintainable

Renovate for automated updates, shellcheck and hadolint in CI, pre-commit hooks, single-command build. Updates tested and reversible.

Quick Start

Up and running

Step 01

Use in a workflow

on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    container:
      image: ghcr.io/wyattau/runner-images/ubuntu:1
    steps:
      - uses: actions/checkout@v4
      - run: make build
Step 02

Pull directly

docker pull ghcr.io/wyattau/runner-images/ubuntu:1

# All flavours:
#   base-universal   git, curl, jq, make, gcc   (190MB)
#   ubuntu           + docker-cli, sudo           (202MB)
#   python           + python3, pip, venv         (204MB)
#   node             + node 22, npm, yarn, pnpm   (259MB)
#   heavy            + node + python + docker     (282MB)
#   rust             + rustc, cargo, rustup       (TBD)
#   go               + go 1.26                    (TBD)
#   java             + openjdk 21, maven          (TBD)
#   dotnet           + .net 8.0 sdk               (TBD)
#   flutter          + flutter 3.44, dart         (TBD)
#
# Tags follow semver: 1, 1.0, 1.0.0, latest
Step 03

Build from source

git clone https://github.com/WyattAu/RunnerImages.git
cd RunnerImages
make build                  # build ubuntu (default)
make build FLAVOUR=ubuntu   # explicit flavour
make verify                 # run verification suite

# Standards: Forgejo Actions Runner Images

Compliance requirements with verification methods, quality gates, and failure modes.

---

## S1: Build Standard

### S1.1 Dockerfile Structure

```dockerfile
# Layer 0: Base image (pinned by digest)
FROM ubuntu:24.04@sha256:<hex> AS base

# Layer 1: BU base packages (shared across all flavours)
FROM base AS bu-base
RUN apt-get update \
  && apt-get install -y --no-install-recommends \
    git=<ver> git-lfs=<ver> openssh-client=<ver> \
    make=<ver> build-essential=<ver> \
    jq=<ver> yq=<ver> \
    curl=<ver> wget=<ver> \
    zip=<ver> unzip=<ver> zstd=<ver> tar=<ver> gzip=<ver> \
    ca-certificates=<ver> openssl=<ver> \
    diffutils=<ver> patch=<ver> file=<ver> tree=<ver> \
  && rm -rf /var/lib/apt/lists/* \
  && rm -rf /usr/share/man/* /usr/share/doc/* /usr/share/info/* \
  && find /usr/bin -type f -executable -exec strip --strip-unneeded {} + 2>/dev/null || true \
  && find /usr/lib -name "*.a" -delete 2>/dev/null || true \
  && find / -perm /6000 -type f -exec chmod a-s {} + 2>/dev/null || true \
  && find / -perm -002 -type f -exec chmod o-w {} + 2>/dev/null || true

# Layer 2: Flavour-specific packages
FROM bu-base AS <flavour>
RUN apt-get update \
  && apt-get install -y --no-install-recommends \
    <flavour-packages>=<ver> \
  && rm -rf /var/lib/apt/lists/* \
  && rm -rf /usr/share/man/* /usr/share/doc/* /usr/share/info/* \
  && find /usr/bin -type f -executable -exec strip --strip-unneeded {} + 2>/dev/null || true \
  && find /usr/lib -name "*.a" -delete 2>/dev/null || true \
  && find / -perm /6000 -type f -exec chmod a-s {} + 2>/dev/null || true \
  && find / -perm -002 -type f -exec chmod o-w {} + 2>/dev/null || true

# User setup (final stage only)
RUN groupadd -g 1000 runner && useradd -u 1000 -g 1000 -m -s /bin/bash runner

ENV HOME=/home/runner
ENV LANG=C.UTF-8
ENV LANGUAGE=C:en
ENV LC_ALL=C.UTF-8
ENV DEBIAN_FRONTEND=noninteractive
ENV PATH="/home/runner/.local/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"

USER runner
WORKDIR /home/runner

ENTRYPOINT ["/bin/bash"]
```

### S1.2 Build Rules

| Rule | Requirement | Violation |
|------|-------------|-----------|
| `--no-install-recommends` | Every `apt-get install` | Adds ~30% unnecessary packages |
| Single `RUN` per layer | `apt-get update && install && clean` in one RUN | Leaves apt cache in intermediate layer |
| Version pins | Every package has `=<version>` | Unpinned = non-reproducible |
| Thinning | Strip, remove man/docs/a/suid in same RUN | Extra layers, wasted space |
| No `COPY` | Nothing copied into the image | Runner images need no application code |

## S2: Versioning Standard

### S2.1 Semantic Versioning

| Bump | Trigger | Example |
|------|---------|---------|
| MAJOR | Base image digest change, breaking removal | 1.x → 2.0.0 |
| MINOR | New tool added, major upstream update | 1.0.x → 1.1.0 |
| PATCH | Security patch, minor upstream update | 1.1.0 → 1.1.1 |

### S2.2 Tag Matrix

| Tag | Points to | Immutable? |
|-----|-----------|-----------|
| `latest` | Latest stable MAJOR | No (moves) |
| `MAJOR` | Latest in major series | No (moves) |
| `MAJOR.MINOR` | Latest in minor series | No (moves) |
| `MAJOR.MINOR.PATCH` | Exact version | **Yes** |
| `sha-<hex>` | Exact image digest | **Yes** |

### S2.3 VERSION File

Every image directory contains `VERSION` with exactly:

```
1.2.3
```

CI reads this file to determine what to build and tag. No other source of truth.

## S3: Reproducibility Standard

### S3.1 Reproducibility Test

Every CI build must:

```bash
# Build 1
docker build --no-cache --progress=plain -t test1 images/<flavour>/
DIGEST1=$(docker inspect --format '{{.Id}}' test1)

# Build 2
docker build --no-cache --progress=plain -t test2 images/<flavour>/
DIGEST2=$(docker inspect --format '{{.Id}}' test2)

# Verify
if [ "$DIGEST1" != "$DIGEST2" ]; then
  echo "FAIL: Build not reproducible"
  echo "Build 1: $DIGEST1"
  echo "Build 2: $DIGEST2"
  exit 1
fi
```

**Failure to reproduce = build is broken = do not merge.**

### S3.2 What Breaks Reproducibility

| Cause | Prevention |
|-------|-----------|
| Unpinned base image tag | Pin by SHA256 digest |
| Unpinned package versions | Pin every package |
| `apt-get update` without pinned mirrors | Use default Ubuntu mirrors |
| Build timestamps in output | `SOURCE_DATE_EPOCH=0` |
| Network-dependent builds | `--network=none` for static builds |
| Host filesystem leakage | No `COPY .` or `ADD .` |

### S3.3 versions.lock Format

```toml
# versions.lock — generated by CI after successful build
# DO NOT EDIT MANUALLY

[base]
image = "ubuntu:24.04"
digest = "sha256:<hex>"

[packages]
git = "1:2.45.0-1ubuntu2"
git-lfs = "2.15.0-1"
openssh-client = "1:9.6p1-4ubuntu0.2"
curl = "8.5.0-2ubuntu10.4"
# ... every installed package at exact version
```

**CI generates this file from `docker run <image> dpkg-query -W`.** The file is committed to the repo.

## S4: Size Standard

### S4.1 Size Budgets

| Budget | Compressed (gzip) | Uncompressed |
|--------|-------------------|--------------|
| Layer 0 (ubuntu base) | ≤ 25MB | ≤ 78MB |
| Layer 1 (BU base) | ≤ 100MB | ≤ 250MB |
| Layer 2 (flavour-specific) | ≤ 100MB | ≤ 300MB |
| **Standard flavour total** | **≤ 225MB** | **≤ 630MB** |
| **Heavy flavour total** | **≤ 350MB** | **≤ 900MB** |

### S4.2 Size Enforcement

```bash
# Measure compressed size
COMPRESSED=$(docker save <image> | gzip -9 | wc -c)
COMPRESSED_MB=$((COMPRESSED / 1024 / 1024))

# Measure uncompressed size
UNCOMPRESSED=$(docker inspect --format '{{.Size}}' <image>)
UNCOMPRESSED_MB=$((UNCOMPRESSED / 1024 / 1024))

# Enforce budget
if [ $COMPRESSED_MB -gt 225 ]; then
  echo "FAIL: Compressed size ${COMPRESSED_MB}MB exceeds budget 225MB"
  exit 1
fi

if [ $UNCOMPRESSED_MB -gt 630 ]; then
  echo "FAIL: Uncompressed size ${UNCOMPRESSED_MB}MB exceeds budget 630MB"
  exit 1
fi
```

### S4.3 Size Regression Detection

CI compares current build size to previous release:

```bash
PREV_SIZE=$(gh api repos/.../releases/latest | jq -r '.body' | grep "Uncompressed:" | awk '{print $2}')
CURR_SIZE=$(docker inspect --format '{{.Size}}' <image>)
REGRESSION=$(echo "$CURR_SIZE > $PREV_SIZE * 1.1" | bc -l)

if [ "$REGRESSION" = "1" ]; then
  echo "WARN: Size increased by >10% ($PREV_SIZE → $CURR_SIZE)"
  # Fail if >20%
  if [ $(echo "$CURR_SIZE > $PREV_SIZE * 1.2" | bc -l) = "1" ]; then
    echo "FAIL: Size increased by >20%"
    exit 1
  fi
fi
```

## S5: Security Standard

### S5.1 Vulnerability Policy

| Severity | Action | SLA |
|----------|--------|-----|
| Critical | Block merge, immediate rebuild | 24 hours |
| High | Block merge, rebuild within 48 hours | 48 hours |
| Medium | Log, rebuild in next nightly | 7 days |
| Low | Log, rebuild in next monthly | 30 days |

### S5.2 Security Scan

```bash
# Trivy scan — fail on critical/high
trivy image --severity CRITICAL,HIGH --exit-code 1 <image>

# Secret scan — fail on any finding
trivy image --scanners secret --exit-code 1 <image>

# SUID scan — fail on any SUID binary (except sudo in flavours that include it)
SUID_COUNT=$(docker run --rm <image> find / -perm /4000 -type f 2>/dev/null | grep -cv '^/usr/bin/sudo$' || true)
if [ $SUID_COUNT -gt 0 ]; then
  echo "FAIL: Found $SUID_COUNT unexpected SUID binaries"
  docker run --rm <image> find / -perm /4000 -type f
  exit 1
fi

# World-writable scan — fail on any finding
WW_COUNT=$(docker run --rm <image> find / -perm -002 -type f 2>/dev/null | wc -l)
if [ $WW_COUNT -gt 0 ]; then
  echo "FAIL: Found $WW_COUNT world-writable files"
  exit 1
fi
```

### S5.3 Supply Chain

| Requirement | Tool | Command |
|-------------|------|---------|
| Image signing | cosign | `cosign sign --key cosign.key ghcr.io/...` |
| SBOM generation | syft | `syft <image> -o spdx-json > sbom.spdx.json` |
| Base image verification | cosign | `cosign verify --key cosign.pub <base-image>` |
| Dependency audit | Renovate | Weekly PR for package updates |

## S6: Testing Standard

### S6.1 Smoke Tests

```bash
#!/bin/bash
set -euo pipefail

IMAGE=$1

# Shell
docker run --rm "$IMAGE" bash --version | grep -q "5\."
docker run --rm "$IMAGE" test -f /bin/bash

# Git
docker run --rm "$IMAGE" git --version | grep -q "2\."
docker run --rm "$IMAGE" git lfs version

# Languages (flavour-dependent)
docker run --rm "$IMAGE" node --version | grep -q "22\."
docker run --rm "$IMAGE" npm --version
docker run --rm "$IMAGE" python3 --version | grep -q "3\.12\."
docker run --rm "$IMAGE" pip3 --version

# Tools
docker run --rm "$IMAGE" docker --version | grep -q "29\."
docker run --rm "$IMAGE" jq --version
docker run --rm "$IMAGE" curl --version
docker run --rm "$IMAGE" make --version
docker run --rm "$IMAGE" gcc --version

# User
docker run --rm "$IMAGE" id runner | grep -q "uid=1000"
docker run --rm "$IMAGE" whoami | grep -q "runner"

# Environment
docker run --rm "$IMAGE" bash -c 'echo $HOME' | grep -q "/home/runner"
docker run --rm "$IMAGE" bash -c 'echo $LANG' | grep -q "C.UTF-8"
```

### S6.2 Compatibility Tests

```bash
#!/bin/bash
set -euo pipefail

IMAGE=$1

# Git clone simulation
docker run --rm "$IMAGE" bash -c '
  git init /tmp/test && cd /tmp/test &&
  git remote add origin https://github.com/octocat/Hello-World.git &&
  git fetch --depth=1 origin main &&
  git checkout -b main FETCH_HEAD
'

# apt-get at runtime
docker run --rm "$IMAGE" bash -c '
  apt-get update && apt-get install -y --no-install-recommends htop &&
  rm -rf /var/lib/apt/lists/* &&
  htop --version
'

# pip install at runtime
docker run --rm "$IMAGE" bash -c '
  pip3 install --user requests &&
  python3 -c "import requests; print(requests.__version__)"
'
```

### S6.3 Size Tests

```bash
#!/bin/bash
set -euo pipefail

IMAGE=$1
COMPRESSED_BUDGET=225  # MB
UNCOMPRESSED_BUDGET=630  # MB

COMPRESSED=$(docker save "$IMAGE" | gzip -9 | wc -c)
COMPRESSED_MB=$((COMPRESSED / 1024 / 1024))

UNCOMPRESSED=$(docker inspect --format '{{.Size}}' "$IMAGE")
UNCOMPRESSED_MB=$((UNCOMPRESSED / 1024 / 1024))

echo "Compressed: ${COMPRESSED_MB}MB (budget: ${COMPRESSED_BUDGET}MB)"
echo "Uncompressed: ${UNCOMPRESSED_MB}MB (budget: ${UNCOMPRESSED_BUDGET}MB)"

if [ $COMPRESSED_MB -gt $COMPRESSED_BUDGET ]; then
  echo "FAIL: Compressed exceeds budget"
  exit 1
fi

if [ $UNCOMPRESSED_MB -gt $UNCOMPRESSED_BUDGET ]; then
  echo "FAIL: Uncompressed exceeds budget"
  exit 1
fi
```

## S7: CI/CD Standard

### S7.1 Build Pipeline

Every push to `main`:

```
1. Build (docker build --no-cache)
2. Reproducibility check (build twice, compare SHA256)
3. Smoke tests (shell, git, tools, user, env)
4. Compatibility tests (git clone, apt-get, pip install)
5. Size tests (compressed + uncompressed within budget)
6. Security scan (Trivy critical/high, secrets, SUID)
7. SBOM generation (syft SPDX 2.3)
8. Push to ghcr.io (if all pass)
9. Sign with cosign
10. Update versions.lock
```

### S7.2 Nightly Pipeline

```
1. Rebuild all flavours (catch upstream patches)
2. Trivy scan all images
3. Compare sizes (alert if >10% increase)
4. Verify reproducibility
5. Update versions.lock if any changes
```

### S7.3 Failure Modes

| Failure | Action |
|---------|--------|
| Build fails | Block merge, investigate |
| Reproducibility fails | Block merge, investigate |
| Smoke test fails | Block merge, investigate |
| Size exceeds budget | Block merge, optimize |
| CVE critical | Block merge, rebuild |
| CVE high | Block merge, rebuild within 48h |
| SUID binary found | Block merge, remove |

## S9: Dependency Standard

### S9.1 Base Image Pinning

| Context | Pin Method |
|---------|-----------|
| Dockerfile | `FROM ubuntu:24.04@sha256:<hex>` |
| CI build | `FROM ubuntu:24.04@sha256:<hex>` (same as Dockerfile) |
| Local dev | `FROM ubuntu:24.04` (tag, for convenience) |

**CI always uses digest. Local dev may use tag.**

### S9.2 Package Pinning

| Package | Pin Strategy |
|---------|-------------|
| System packages | `apt-get install pkg=<version>` from Ubuntu repo |
| `build-essential` | Metapackage, pinned transitively |
| External tools | Pinned to exact version in Dockerfile |

### S9.3 Update Mechanism

| Component | Tool | Frequency |
|-----------|------|-----------|
| Base image digest | Renovate | Weekly |
| Package versions | Renovate | Weekly |
| Tool versions | Manual PR | On release |
| Security patches | Renovate | Within SLA |
